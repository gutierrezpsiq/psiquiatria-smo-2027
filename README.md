# Fluxos de Atendimento — Psiquiatria SMO 2027

Protótipo interativo para orientação de fluxos de atendimento da Psiquiatria Ocupacional do SMO.

## Acesso

Após ativar o GitHub Pages neste repositório, a ferramenta estará disponível em:
https://gutierrezpsiq.github.io/psiquiatria-smo-2027/

## Publicação

No GitHub, abra **Settings > Pages**, selecione **Deploy from a branch**, escolha **main** e **/(root)**, e salve.

O arquivo `index.html` contém a aplicação, sem dependências externas. O arquivo `.nojekyll` evita processamento por Jekyll.

## Atenção

Este é um protótipo de apoio aos fluxos e não substitui avaliação clínica. Antes da divulgação pública, conferir os contatos institucionais de plantão presentes na ferramenta e a autorização para divulgação do protocolo.

## Atualização

Substitua `index.html` por uma versão revisada e faça commit na branch `main`. O endereço permanece o mesmo.
